## This Portfolio

This repo is my personal 3D portfolio site built with React 18, TypeScript, Three.js, React Three Fiber, and GSAP. It features a full animated 3D character scene, scroll-driven storytelling, custom cursor, and a physics-based tech stack canvas.

```
src/
├── components/
│   ├── Character/     # Three.js scene, encrypted model, GSAP animations
│   ├── styles/        # Per-section CSS modules
│   ├── utils/         # GSAP scroll timelines, split-text, initial FX
│   ├── Landing.tsx    # Hero section
│   ├── About.tsx
│   ├── WhatIDo.tsx    # Hover-expand skill panels
│   ├── Career.tsx     # Timeline
│   ├── Work.tsx       # Project carousel with role badges
│   ├── TechStack.tsx  # Physics-based 3D sphere canvas
│   └── Contact.tsx
├── context/           # Loading state provider
└── data/              # Bone/animation data
```

**Run locally**

```bash
npm install
npm run dev        # → http://localhost:5173
```

**Deploy** — every push to `main` triggers GitHub Actions → GitHub Pages automatically.
